        Software updates v–

        MyGPT updates itself from the official codero-sus/MyGPT branch. Checks are manual; installing needs you to confirm the exact commit. Your learned memory, weights and settings in data/ are never touched. Restart the server to finish an install.

        Brain architecture –

        v1.11 ships a real decoder-only transformer: multi-head causal self-attention, pre-layer-norm blocks, GELU feed-forward, learned positional embeddings and tied input/output embeddings — trained with Adam, warmup + cosine learning-rate decay and gradient clipping. Its gradients are verified against numerical differentiation.

        Self-training checking…

        The brain keeps learning in a background thread — but only while you are not waiting on it. Each request tells the trainer to stand down, it waits a moment after your last reply, and it duty-cycles so its own CPU time stays under the share below. A training round triggered by a learning event is queued, never run on the request thread.

            Local LLM · Cortex LLMHoster …

            Open questions MyGPT can't answer itself can be routed to a model hosted locally by Cortex LLMHoster (OpenAI-compatible API — no cloud, prompts never leave this machine). Answers are learned back into MyGPT's own memory. When Cortex is off or unreachable, the self-trained brain keeps answering.

              Local LLM · Ollama …

              MyGPT can also route open questions to models running on Ollama (native JSON API). Pull a model (ollama pull llama3.2) and it appears here. Like Cortex, Ollama serves models — MyGPT's own NumPy brain is what trains.

                Model checkpoints 0

                Snapshots of MyGPT's trained weights, saved under _model_trained/. Save one any time — or just ask in chat: “checkpoint the model” (or “train and save the model”). Load a checkpoint back to make it the active brain.
