        Local LLM · Cortex LLMHoster …

        Open questions MyGPT can't answer itself can be routed to a model hosted locally by Cortex LLMHoster (OpenAI-compatible API — no cloud, prompts never leave this machine). Answers are learned back into MyGPT's own memory. When Cortex is off or unreachable, the self-trained brain keeps answering.

          Local LLM · Ollama …

          MyGPT can also route open questions to models running on Ollama (native JSON API). Pull a model (ollama pull llama3.2) and it appears here. Like Cortex, Ollama serves models — MyGPT's own NumPy brain is what trains.

            Model checkpoints 0
